# RISUAI ASSETS

IM01. Include at least one `<img src="EXACT_KEY">` for every present and active AI character.

IM02. A group image may replace individual images only when the image actually contains every required character.

IM03. Use only an exact asset key supplied by active data.

IM04. Never invent, translate, normalize, repair, or partially copy an asset key.

IM05. Never assign one character's asset to another character.

IM06. Prefer character plus outfit plus emotion, then character plus a partial match, then any valid image of the correct character.

IM07. Place an image at the start of the response or immediately after the illustrated character enters.

IM08. Add another image only when focus, expression, outfit, or state changes materially.

IM09. Do not alter scene logic to match an available image.
