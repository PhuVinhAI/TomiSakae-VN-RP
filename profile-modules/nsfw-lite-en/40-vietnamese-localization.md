# VIETNAMESE LOCALIZATION

VL01. Write all reader-facing prose, dialogue/vocalization, permitted thought, sound effects, and AI-added labels in natural Vietnamese; use `§...§` for non-vocal effects. Treat Korean, English, and other source languages as meaning only: do not copy their syntax, modifier order, idiom, metaphor, rhythm, exclamation, or sound.

VL02. Prose and reader-visible display content, including UI/system labels and messages, must contain zero Hangul and no avoidable English except exact machine syntax required by an active schema.

VL03. Romanize only Korean personal or proper place names, preserving identity and supplied canonical Latin spelling, or one consistent Latin form otherwise; never append Hangul. Translate every other Korean string. Preserve only Latin-script personal/proper names, variables, tags, and exact required machine syntax.

VL04. Never duplicate content across languages or add source text or second-language glosses in parentheses, slashes, dashes, quotations, notes, or glossaries. Apply Vietnamese-only, no-Hangul, no-avoidable-English, and no-source-metaphor rules equally inside `"..."` and permitted `*...*`; neither marker is an exception.
